# Welby skills

Welby's own Claude Code skills. Each folder is one skill, with a `SKILL.md` inside.

## How to install one

1. Go to https://skills.getwelby.com and find the skill.
2. Click "Send to an agent". It installs into Agent Console.
3. In your agent, type `/` plus the skill name, then your request.

Skills only show up on the site after they are reviewed.

## Adding a skill

Open a pull request with a new folder named after the skill. The `name` in `SKILL.md` must match the folder name: lowercase letters, digits and single hyphens. Keep it free of patient data, secrets and keys.
